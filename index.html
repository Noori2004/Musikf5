Connect Google Drive

This needs your own Google Cloud OAuth credentials — Google doesn't allow a shared key for this. One-time setup:
1. Open console.cloud.google.com, create a project.
2. Enable the Google Drive API and Google Picker API.
3. Create an OAuth Client ID (Web application) — add the URL this page is hosted at as an Authorized JavaScript origin.
4. Create an API Key (restrict it to the Picker API).
5. On the OAuth consent screen, add your own Google account as a test user.
Note: this only works when the page is served over http/https — opening the file directly (file://) won't let Google sign you in.
